# Blog_Muuusica

Atividade proposta com o intuito de explorar e aplicar os principais recursos da biblioteca Bootstrap. O objetivo foi desenvolver uma interface web responsiva utilizando os componentes, classes utilitárias e sistema de grid do Bootstrap. Durante a prática, os alunos testaram botões, cards, navegação, responsividade e personalização de estilos, consolidando o conhecimento sobre design moderno e desenvolvimento front-end com frameworks.

Na instituição Senai, pelo curso "Desenvolvimento de Sistemas Web"
